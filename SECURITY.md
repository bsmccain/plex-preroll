# Security reports

Report suspected vulnerabilities privately to [brian@zarquan.com](mailto:brian@zarquan.com). Include the affected version or commit, steps to reproduce, and the impact you observed. Remove Plex tokens and other credentials from examples and logs.

Please avoid public issues or pull requests containing an undisclosed vulnerability. The maintainer will coordinate a fix and disclosure with you by email.

Security fixes are applied to the current `main` branch. Use a current Go release when building the application so that standard-library security fixes are included.
